# Campus Application Helper / 秋招网申助手

一个 Tampermonkey userscript，用于秋招、校招和日常网申过程中维护本地个人资料，并快速复制需要填写的信息。

它是本地资料管理和复制辅助工具，不是自动投递或 AI 自动网申系统。

## 当前功能

- 分类 → 卡片 → 字段三级资料结构
- 分类、卡片、字段的新增、修改、删除与拖拽排序
- 短字段、长文本及时间区间的快速复制
- 本地资料保存，以及 JSON 导入 / 导出
- 编辑已有资料时自动保存，支持 Ctrl/Cmd+Z 撤回资料操作
- 记住最近浏览的分类、卡片与卡片滚动位置
- 可拖动、可调整大小的面板
- 右侧分类栏也可用于拖动面板，普通点击仍可切换分类
- 卡片按钮响应式换行
- 页面样式隔离；当前版本使用 Shadow DOM 隔离

脚本会兼容并迁移可识别的旧版本地数据；导入或升级前仍建议先导出 JSON 备份。

## 安装与使用

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 安装本仓库中的 `campus-application-helper.user.js`。
3. 打开任意网申页面，从脚本面板建立或导入自己的资料；可参考 [匿名示例](examples/profile.example.json)。
4. 在需要填写的信息旁复制对应内容，并自行粘贴、检查与提交。

## 隐私与边界

- 脚本不会自动提交网申表单。
- 脚本不会自动向外部服务器上传用户资料。
- 数据默认保存在 Tampermonkey 本地存储中。
- 本公开仓库不包含作者的真实网申资料；示例数据均为虚构匿名数据。
- 用户应自行确认复制和填写信息的准确性，并自行负责导入、导出文件的保管。
