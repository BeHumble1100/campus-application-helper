# 开发演进

Campus Application Helper 最初是一个通用信息库：用户在网申页面中从本地保存的常用信息里选择内容，再手动填写。

随后版本围绕稳定性、收藏、目标锁定、字段识别和快速候选展开，尝试减少在不同网站之间查找资料的成本。快捷填充阶段提供过输入框旁的候选和手动填入能力，但始终不自动提交表单。

产品方向后来逐步放弃复杂的自动字段识别与自动填充，转向更稳定、可控的“本地个人资料库 + 手动复制粘贴”模式。这样用户能在每次填写前自行核对信息，也减少了不同招聘网站页面结构变化带来的影响。

v3.x 将零散字段升级为分类 → 卡片 → 字段三级结构，并逐步加入 CRUD、拖拽排序、面板移动、面板缩放和响应式换行。后续版本继续强化 CSS 隔离，并使用 Shadow DOM，使脚本界面更不容易受到招聘网站样式干扰。

最新迭代继续打磨手动资料管理体验：资料操作可用 Ctrl/Cmd+Z 撤回，刷新后可恢复分类、卡片和滚动位置；右侧分类栏既能用于拖动窗口，也保留普通点击切换分类。编辑既有内容时自动保存，而新增内容仍要求显式保存，以避免留下半成品记录。
